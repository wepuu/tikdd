# TikDD design references

## Homepage direction reference

- Reference: [homepage.png](homepage.png)
- Added: 2026-08-04
- Role: primary visual reference for the three homepage/resolver directions in Phase 2

The image establishes a bright, lightweight surface, blue-to-violet primary action, compact
platform support chips, and a visible input-to-format-selection journey. It is a direction reference,
not a pixel-perfect implementation target.

When the visual phase begins:

1. Product Design must generate exactly three distinct directions grounded in this image and the
   working TikDD flow.
2. The `frontend-design` skill must critique each direction for intentional typography, meaningful
   structure, product-specific visual identity, restrained motion, and template-like defaults.
3. Do not copy unsupported claims such as guaranteed speed, original quality, unlimited platform
   support, absolute privacy, user counts, or free service commitments.
4. Use real platform icons from an approved icon source; do not recreate them with text symbols,
   emoji, CSS drawings, or improvised SVG assets.
5. Select one direction before production UI changes, then compare reference and implementation at
   matching desktop and mobile states during visual QA.
